Bausteine

Klick fügt einen Knoten ein. Knoten ziehen, um sie zu verschieben. Vom Punkt unten am Knoten zu einem anderen Knoten ziehen, um sie zu verbinden. Entf löscht das Ausgewählte.

Was ist hier echt?

Jede Aktivität ist eine Temporal-Activity in einem eigenen Dienst. Der Graph wird beim Start eines Falls in die Workflow-Historie geschrieben; deshalb ist jede Version für laufende Fälle eingefroren.

Eigenschaften

Knoten auswählen, um ihn zu bearbeiten.

Prozess als JSON

Genau das wird gespeichert und dem Temporal-Workflow beim Start als Argument übergeben.
